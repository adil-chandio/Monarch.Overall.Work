## Acceptance gates for the eventual forensic dossier

1. **Per-source provenance:** canonical URL/channel ID, acquisition route, content/version match, checksum, audio/video duration, frame timestamps and disclosure of re-encoding or unknown provenance.
2. **Full decode:** every frame indexed with actual PTS; flag variable cadence, duplicate/near-duplicate frames and corrupted samples. Export exact source frame IDs, not word-proportional estimated timings.
3. **Second-by-second ledger:** each interval gets scene/action/camera evidence, character posing/eyelines/contact, object state/continuity, materials, light/shadow, depth/readability, captions and audible event notes. Unknown fields stay unknown.
4. **Frame neighborhoods:** check adjacent native frames around every verified cut, contact/release, deformation, cutaway, major scale move, caption change and apparent defect. Automated high-difference peaks are candidates, not a cut count.
5. **Audio:** timestamp narration and visible-text differences; label ASR separately from verified listening; measure actual mix; verify perceived SFX/music/voice synchronization rather than invent stems from the mixed waveform.
6. **Evidence types:** tag every finding **observed / measured / inferred / unavailable**. Exported pixels cannot recover exact renderer, focal length, rig, texture source, project settings, budget or authorship of each asset.
7. **Coverage accounting:** list frames decoded, frames actually inspected, native-detail checks, source time windows listened to, unresolved portions and whether API sampling skipped frames. A 1fps or 5fps API pass must never be called every-frame inspection.
8. **Synthesis, not copying:** compare causal visualization, complete visible actions, acting, motivated camera and payoff across the ten; do not reuse source footage, narration, character assets or music in a production.
