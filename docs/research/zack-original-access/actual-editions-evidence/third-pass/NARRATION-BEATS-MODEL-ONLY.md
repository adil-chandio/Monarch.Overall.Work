## Bounded craft deductions

These are interpretations of this ten-edition sample, not creator project settings, performance attribution or universal laws:

1. **Hook forms vary.** Consequence-first, familiar-assumption reversal, part-building and a first-person hypothetical all occur. A single mandatory question opener would erase this variation.
2. **An object/relationship remains causal.** Chambers drive flow; removal requires reconnection; support changes a hanging body's state; a large tail receives a balance explanation. This is more specific than “add motion” or “make the voice faster.”
3. **Chronology is flexible, mechanism continuity is not disposable.** Concert explicitly describes the consequence before the expected catch. A deliberate narrative reorder differs from unexplained asset teleportation.
4. **Holding can be action.** Rescue support and adaptive balance continue after the biggest displacement. Maintaining support relationships and secondary motion can carry the beat.
5. **Conclusions change function.** Some end with circulation, adaptation or a rescue payoff; others warn, pivot to a coda, or leave an apparent response unresolved. This cohort does not establish one universal loop-ending formula.
6. **Audio models need correction.** Two obvious name/spelling review cases and the unexplained horse candidate expose the risk of plausible machine output. Neither confident ASR nor visually plausible event labels can replace actual listening.
