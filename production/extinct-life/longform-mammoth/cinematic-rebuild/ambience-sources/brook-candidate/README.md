Human listening for interference, unwanted sounds, looping and suitability is still required before publication.

The stream workprint takes seconds 8–24 of this derivative at 20% amplitude, with a 0.8s fade-in and 1.5s fade-out, mixed under the existing narration/score with peak limiting. This is constructed ambience, not a documentary field recording, and has not been continuously auditioned or approved.
