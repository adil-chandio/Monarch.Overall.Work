# Material/model candidates — provenance and limits

These files are candidate materials for 3D meshes, **not** backgrounds or photographic slides. They are not evidence of what Wrangel Island looked like, and their exact identity with the listed author-distributed master files has not been verified. Review their use and provenance before publication.

## Grass Medium 01 candidate

`polyhaven-grass/grass-medium-01.glb` was obtained from [`CBaileyDev/Life-Theory`](https://github.com/CBaileyDev/Life-Theory/blob/HEAD/assets/models/grass_medium_01.glb), blob `f704196fce23598c9a8bc4a988fe6bc9e013f3e7`, SHA-256 `6c66ebc99659a5d29b530cd17588f3680a4c0bc5b2179d3046d0eaf43cbf161f`. Its embedded names and geometry suggest a compressed derivative of [Poly Haven Grass Medium 01](https://polyhaven.com/a/grass_medium_01), credited there to modeler Rico Cilliers and photographer Rob Tuytel, CC0. The GitHub README describes bundled grass models as CC0, and the GLB identifies glTF-Transform as its generator, so this is not presented as an unmodified master. Asset identity/rights and alpha-texture handling still require verification. It depicts modern grass, not a scientifically established Wrangel fossil plant. It is a 3D mesh with photographic material textures; it is not an image slide.
