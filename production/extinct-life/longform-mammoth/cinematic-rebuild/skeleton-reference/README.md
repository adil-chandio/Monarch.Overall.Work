# Skeleton reference exhibit — work in progress

This short, silent, native-3D exhibit is an asset inspection, **not the film**. The static mount is not a living animal rig, nor evidence of a Wrangel specimen or either of the genomes in the 2017 study. The environment is an invented museum stage; the second framing does not isolate the head effectively. Neither the setting nor the specimen has been scientifically reviewed.

The OBJ was downloaded from [Jmeshesha/Woolly-Mammoth-Visualization](https://github.com/Jmeshesha/Woolly-Mammoth-Visualization/blob/main/Assets/3d%20Models/Skeleton/Low%20Poly%20Mammoth/woolly-mammoth-150k.obj), Git blob `1250874a8024651bb1340a37a98a81c3052f0fc0`, SHA-256 `be6dc1dddd27fa9f75a1fed1fa84b9d193b180ac51746fffc3acfafc984046e6`. The repository attributes its skeleton to the Smithsonian. A [Smithsonian 150k skeleton scan](https://commons.wikimedia.org/wiki/File:Woolly-mammoth-150k_(Smithsonian_Institution).stl) is identified as CC0, but this third-party OBJ has **not** been independently matched to that master and its provenance/rights must be confirmed before public distribution. Do not label it as a specific specimen solely on this basis. The project’s MIT code licence does not automatically clear included third-party assets.

From the repository root, `node production/extinct-life/longform-mammoth/cinematic-rebuild/skeleton-reference/inspect.mjs` checks six seeks and writes stills to the ignored `.cache/mammoth-skeleton-reference`. Requires Three.js, Playwright and `@sparticuz/chromium`. Such checks are structural only: they do not establish specimen identity, quality, science or rights clearance.
