# Title shortlist

B is the selected launch pairing. A is a search-led challenger. This is editorial prioritisation, not measured CTR.

1. **A Lost World Hidden in Greenland’s Dirt** (39 characters; package B) — Selected launch pairing: object-to-world title; chosen B thumbnail supplies the two-million-year age.
2. **2-Million-Year-Old DNA Revealed Greenland’s Lost World** (54 characters; package A) — Search/browse challenger; initial editorial leader before user selected B artwork.
3. **Why Was a Mastodon in Greenland?** (32 characters; package C) — Protagonist-led contradiction; directly paid off by the opening.
4. **What 2-Million-Year-Old DNA Revealed About Greenland** (52 characters; package D) — Search-led alternative; slightly less emotional.
5. **Greenland’s Dirt Held Clues to a Lost World** (43 characters; package E) — Evidence-led and cautious; weaker numerical specificity.
6. **The Lost World Written in Greenland’s DNA** (41 characters; package F) — Poetic broad-audience alternative; clarify ancient sediment DNA in description.
7. **How Ancient DNA Revealed Greenland’s Lost World** (47 characters; package G) — Mechanism-led; suitable for science-learning intent.
8. **A Mastodon’s DNA Changed the Picture of Greenland** (49 characters; package H) — Belief-update angle; avoids claiming the greener past was wholly unknown.
9. **The Ancient DNA Hidden in Greenland’s Frozen Dirt** (49 characters; package I) — Concrete object + place; payoff less explicit.
10. **Greenland Was Once a Very Different World** (41 characters; package J) — Broad transformation; lacks the unique DNA hook.
11. **How Do You Find an Animal Without Its Bones?** (44 characters; package K) — Method mystery; use only if willing to sacrifice place/age search specificity.
12. **The Giant Hidden in Greenland’s Genetic Past** (44 characters; package L) — Animal-led curiosity; more abstract than C.
13. **What Survived Greenland’s Lost Forest?** (38 characters; package M) — Question directly paid off by genetic fragments; not living survivors.
14. **2-Million-Year-Old DNA—and a Vanished Greenland** (47 characters; package N) — Specific age and transformation; somewhat literary.
15. **A Handful of Dirt, a World Lost to Time** (39 characters; package O) — Cinematic brand option; least searchable of the leading candidates.
