# CMU 35_17 pose-control research guide

This lossless atlas contains 25 projected, pose-only frames, not stock footage or a photograph. It is for a one-second LTX-2.3 research test, not a final shot. The guide has imperfect first-frame alignment, approximate face placement, no measured finger positions, and no verified foot contacts. The root translation was removed for a tracking-camera hypothesis; the side view and 2D proportions are estimates. The prior StableAnimator model failed even with similar CMU controls; that result does not prove this pipeline will work.

Source: converted CMU 35_17 BVH from `konyshevgmbh/cmu-mocap` commit `5db259a8c485c18d945b1be68d8a943242cb98ef`, source SHA-256 `50c6469efea1edbba0f7acd46b1fa72e0b74b78e1698aa1b441990bd2a78d730`, 120 Hz, samples 20–140 inclusive at 24 fps. Generated by `make_cmu_pose_atlas.py` and `run_tall_v5_mocap_to_poses.py` (Python `bvh`, Pillow, NumPy). The source has not been added to this repository.

The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217. CMU permits inclusion in commercial products but prohibits resale of the motion data itself, even in converted form; review the applicable CMU terms and conversion provenance before publication. ## 73-frame landscape research guide

`cmu-35-17-wide-retarget-73f-research.png` is a pose-only, non-textured atlas (8×10 tiles of 832×448; 73 used). `make_cmu_wide_retarget.py` generates it from the same source hash above. It repeats the approximately matched 35_17 frame interval 35–124 four times, sampled every five source frames at 24 fps. Per-bone 2D similarity transforms fit the first pose to the *already-public* generated `shot-04.jpg`, not the original photo. Its first-frame overlay and all pose frames were reviewed locally; the cyclic guide is approximate, lacks measured 3D retargeting and foot contact, and cannot guarantee plausible anatomy, smooth ground contact, or non-repetitive output. It is for testing only, not an approved film.
