# Rear-view walk research

This is an experimental pose-guided test, not a final shot. The motion source is CMU 07_05, downloaded privately at run time. The input images are previously approved generated keyframes, not the original reference photo. Because the rear view has no visible face, the identity detector uses an additional generated side portrait. Realism, wardrobe, anatomy, identity, temporal stability, foot contact, scene/camera motion and third-party licenses must be verified separately. The background is not yet camera-tracked.
