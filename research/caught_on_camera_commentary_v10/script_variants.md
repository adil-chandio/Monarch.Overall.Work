## Variant B — instant-karma / commentary

## Variant C — Hinglish punchline

- Test only after A/B; do not mix languages inside a single caption line.

## Non-negotiable rules
1. No logo, "hey guys", "wait for it" as a substitute for a real hook.
2. First caption ≤7 words; all captions high-contrast and clear of faces/UI.
3. CTA only in final 2–3s; never replace payoff with "comment part 2".
4. Voiceover must add analysis/opinion/context; a VO that only narrates visible action is not enough under 2026 Shorts originality guidance.
5. Write all claims from verified clip/source facts; no invented date, location, injury or outcome.
6. Read-aloud cut pass: remove 20–30% after timing.
