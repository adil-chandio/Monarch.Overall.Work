# Cinematic reference-inspired celebrity POV test

Original fictional 60-second landscape 2D test: 960×540, 24 fps, 1,440 generated frames. The user-supplied reference informed lighting, layered scenery, scale changes, reaction inserts and labels; no source imagery, reference character design or audio was copied. All visuals are rendered as code-generated geometry, gradients and effects. Existing selected synthetic narration is reused, with an original procedural bed; captions are paraphrases. This is not a verified private routine, likeness or endorsement.

Install Pillow, NumPy and imageio-ffmpeg, then run:

```sh
python showreel/cinematic_pov/render.py --output deliverables/monarch-cinematic-reference-pov.mp4
```

This is a rough test, not a premium or complete reference match: details, acting, ball contact, camera, staging and audio quality still need work. It is an illustrated 2D animation with simulated camera motion, not physical 3D. Scope and QC limitations: `docs/repo-intel/REFERENCE-VERSUS-POV-VISUAL-REVIEW.md`.
